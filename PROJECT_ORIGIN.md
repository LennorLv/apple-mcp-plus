# Project origin / 项目来源

Apple MCP Plus is derived from [supermemoryai/apple-mcp](https://github.com/supermemoryai/apple-mcp), originally created by [Dhravya Shah](https://github.com/dhravya) and the supermemory team. GitHub marks the upstream repository as archived and read-only (archived January 1, 2026; checked October 11, 2026).

The upstream project is no longer actively maintained. This independent repository was established for personal use and continued maintenance. It retains the original MIT license and copyright notice. It is not an official release from the original authors.

Changes include repaired local queries and error handling, native Notes checklist reads, an explicit EventKit read backend for Reminders and Calendar, permission diagnostics, and removal of Maps and its desktop automation. The public repository begins with a clean source snapshot. Local acceptance records and old installation bundles are excluded from its Git history.

Thank you to Dhravya Shah, the supermemory team, and the upstream contributors for building and sharing Apple MCP.

Apple MCP Plus 来源于 [supermemoryai/apple-mcp](https://github.com/supermemoryai/apple-mcp)，由 [Dhravya Shah](https://github.com/dhravya) 和 supermemory 团队创建。GitHub 显示原仓库已于 2026 年 1 月 1 日归档并设为只读，核验日期为 2026 年 10 月 11 日。

由于原项目已经归档，为满足自用需要，我们另建此独立仓库进行持续维护，保留原有 MIT 许可证和版权声明。本仓库由独立维护者维护。

主要调整包括修复本地查询和错误处理、读取备忘录原生清单状态、为提醒事项和日历提供显式 EventKit 查询后端、增加权限诊断，以及移除地图和桌面模拟操作。公开 Git 历史从整理后的源码快照开始，不包含本机个人验收记录和旧安装包。

感谢 Dhravya Shah、supermemory 团队及原项目贡献者的工作和开源分享。
